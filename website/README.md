# Netlify Deployment

This website is configured for easy deployment on [Netlify](https://www.netlify.com/).

## Quick Deploy
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/openimis/openimis-be-provider_contract_py)

## Manual Deployment
1. Drag and drop the website/ folder to [Netlify Drop](https://app.netlify.com/drop)
2. Or connect your GitHub repo and set build settings:
   - Build command: (leave empty)
   - Publish directory: website
